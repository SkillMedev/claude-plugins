# Skill Me plugins for Claude Code

Install `skillme` for the Skill Me connector (search and install any of 2,500+ skills); install a pack plugin to get that pack as local skills.

```bash
claude plugin marketplace add SkillMedev/claude-plugins
claude plugin install skillme@skillme
claude plugin install qa-test-automation@skillme   # optional pack
```

- **skillme** — Connect Claude Code to Skill Me: search 2,500+ agent skills, install them into your library, and load them in any session.
- **qa-test-automation** — For engineers who don't trust their test suite: catch real bugs and kill the flake. 9 skills from the Skill Me catalog.
- **mobile-app-engineering** — For mobile engineers: build native + cross-platform apps and ship them past store review. 8 skills from the Skill Me catalog.
- **database-performance** — For backend engineers: make slow queries fast and keep production Postgres healthy. 8 skills from the Skill Me catalog.

Skills are MIT-licensed SKILL.md files from [skillme.dev](https://skillme.dev/?utm_source=github&utm_medium=readme&utm_campaign=claude-plugins). Generated from the Skill Me catalog; do not edit by hand.
